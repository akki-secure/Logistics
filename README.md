## 🚜 最初の機能：リーチリフト3Dシミュレーション

リーチリフトを3Dモデルで再現した初期実装です。

### ファイル構成

```
scenes/
  Main.tscn               ← カメラ・ライト・地面の起動シーン
  ReachLift.tscn          ← リーチリフトの3Dモデル
scripts/
  ReachLiftController.gd  ← リーチリフトの操作スクリプト
```

### リーチリフトのパーツ

積み木（Mesh）を組み合わせて構成しています。

| パーツ | 積み木の種類 | 色 |
|---|---|---|
| 車体・バッテリー | BoxMesh（直方体） | 黄色 |
| マスト・リーチアーム | BoxMesh（直方体） | ダークグレー |
| フォーク（爪） | BoxMesh（直方体） | ライトグレー |
| タイヤ | CylinderMesh（円柱） | 黒 |
| ヘッドガード | BoxMesh（直方体） | 黄色 |

## 📦 追加機能：パレット実装

> **ブランチ：** `feat/pallet`

リーチリフトのフォークを差し込める**パレット**を追加しました。

### パレットの種類（全4種）

| 種類 | サイズ | 外観 |
|---|---|---|
| 🟫 木製パレット（大） | 1.1m × 1.1m | 茶色・5枚の天板ボード |
| 🟫 木製パレット（小） | 0.8m × 0.8m | 茶色・コンパクト |
| ⬛ プラスチックパレット（大） | 1.1m × 1.1m | ダークグレー・格子溝パターン |
| ⬛ プラスチックパレット（小） | 0.8m × 0.8m | ダークグレー・コンパクト |

### 画面イメージ（配置図）

```
         カメラ視点（右後方から見下ろし）
         ┌─────────────────────────────┐
         │         （空・地面）         │
         │                             │
         │  🟫木小  🟫木大             │
         │        🚜リーチリフト        │
         │  ⬛プラ小 ⬛プラ大           │
         │                             │
         └─────────────────────────────┘
```

### フォーク隙間の構造

パレット底面にリーチリフトのフォーク（幅0.12m）が入る**2本の隙間**があります。

```
上から見たパレット断面図:

  ┌────────────────────────────────────┐  ← 天板
  │                                    │
  │ 左桁 │  隙間①  │ 中央桁 │  隙間②  │ 右桁 │
  │                                    │
  └────────────────────────────────────┘
           ↑ フォーク左    ↑ フォーク右
```

### ファイル構成

```
scenes/
  Pallet.tscn     ← パレットシーン（Pallet.gd をアタッチ）
scripts/
  Pallet.gd       ← パレット生成スクリプト
```

### GDScript の学習ポイント

```gdscript
# enum：決まった選択肢を名前で管理する型
enum PalletType { WOOD, PLASTIC }   # 0=木製, 1=プラスチック
enum PalletSize { LARGE, SMALL }    # 0=大,   1=小

# @export：エディタのInspectorから値を変更できる変数
@export var pallet_type: PalletType = PalletType.WOOD
@export var pallet_size: PalletSize = PalletSize.LARGE

# _ready()：ノードが登場した瞬間に1回だけ自動で呼ばれる
func _ready() -> void:
    _build_pallet()
```

## 🚚 追加機能：ウイングトラックとパレット積み込み

> **ブランチ：** `feature/truck-wing`

4トン級の**ウイングトラック**を追加し、リーチリフトでパレットを荷台へ積み込めるようにしました。

### ウイングトラック

| 項目 | 内容 |
|---|---|
| 荷台サイズ | 6.2m × 2.2m |
| 荷台の床高 | 1.1m |
| 屋根の高さ | 3.2m |
| 配置 | 横向き（`Main.tscn` 内の座標 -3, 0, -8） |

- リーチリフトが近づくと、**近い側のウイングが自動で開きます**。離れると閉じます。
- トラックはスクリプト（`Truck.gd`）でコード生成しています。

### パレットの積み込み

- **P キー**でパレットを「掴む」「置く」ができます（物理演算なし）。
- 荷台の床（高さ1.1m）に置けます。
- すでにパレットがある位置には置けません。「他のパレットと重なっています」と画面に表示されます。
- 複数枚のパレットを積み込めます（位置のスナップはありません）。

### 既知の制約

- リフトに衝突判定がなく、トラックやパレットをすり抜けます。
- フォークが届かない奥側の列には積めません。

### ファイル構成

```
scenes/
  Truck.tscn               ← ウイングトラックシーン
scripts/
  Truck.gd                 ← トラック生成・ウイング自動開閉
  Pallet.gd                ← グループ登録・フットプリント取得を追加
  ReachLiftController.gd   ← Pキーで掴む/置く操作を追加
```

<a id="controls"></a>

## 🎮 リーチリフトの操作方法

| キー | 操作 |
|---|---|
| **F** | 前進 |
| **B** | 後退 |
| **L** | 左旋回 |
| **R** | 右旋回 |
| **↑ / ↓** | フォークの上昇 / 下降 |
| **← / →** | フォークのチルト |
| **E** | ライトの点灯 / 消灯 |
| **V** | 一人称視点の切り替え（もう一度押すと元の視点） |
| **右クリック** | カメラ回転（三人称視点のとき） |
| **P** | パレットを掴む / 置く |

## ⚙️ セットアップ

1. [Godot 4.7](https://godotengine.org/) をインストール
2. このリポジトリをクローン
   ```bash
   git clone https://github.com/akki-secure/Logistics.git
   ```
3. Godotでプロジェクトを開く（`project.godot` を選択）
4. `Main.tscn` を開いて ▶ 再生
